# ADR 0003 — Pas de serveur MCP pour les outils GitLab

**Statut** : proposé (relecture du propriétaire en attente — ticket #320)

## Contexte

Les outils GitLab (lectures directes, écritures par plan approuvé) pourraient être exposés via le protocole
MCP (Model Context Protocol), ou consommés depuis des serveurs MCP tiers. Il faut décider si Foreman en
a besoin, pour le PoC comme pour la v1.

## Décision

**Pas de serveur MCP pour les outils GitLab, ni pour le PoC ni pour la v1.**

Foreman joue déjà le rôle de client d'outils : le catalogue est présenté au modèle, et chaque appel passe par
`Gateway.read` (matrice, audit, `mask_for_model`, aliasing de l'ADR 0002, budgets de tour). Un serveur MCP
serait un nouveau point d'entrée à authentifier, à cloisonner par projet et à auditer, et enverrait des
données à d'autres modèles que ceux couverts par l'ADR 0002.

### Règles

1. **La gateway reste le seul chemin.** Ne jamais utiliser le paramètre `mcp_servers` de l'API Anthropic ni
   un outil dont l'exécution sort de la gateway. Un test de structure l'impose (`mcp_servers`, `import mcp`
   et `from mcp` sont interdits sous `backend/src/foreman`).
2. **Fournisseur qui n'offre que MCP** : l'adapter derrière un `ToolAdapter` dans `integrations/<x>/`. Les
   outils sont déclarés en YAML (classe, réversibilité, portée), **jamais importés automatiquement** depuis
   `tools/list`.
3. **Accès depuis un IDE ou Claude Desktop** : serveur MCP **en lecture seule** dans `surfaces/mcp`,
   uniquement les outils `read` du catalogue. Chaque appel est un `Gateway.read` avec un acteur authentifié,
   une sortie masquée et limitée. Les écritures passent seulement par `propose_plan` puis approbation.

## À revoir si

- un besoin d'accès externe est exprimé (IDE, Claude Desktop, autre agent) ;
- une intégration à ajouter n'a pas d'API REST.

## Conséquences

- Aucun nouveau point d'entrée ni nouvelle surface d'authentification.
- Le périmètre des données envoyées reste celui de l'ADR 0002.
- Un fournisseur MCP-only coûte un adaptateur écrit à la main, relu en PR.
