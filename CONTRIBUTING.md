# Contribuer

1. Créez une branche courte depuis `main` (`feat/...`, `fix/...`).
2. `make install` puis `make check` avant chaque commit.
3. Ouvrez une PR petite, avec le modèle fourni. Les gros chantiers se découpent en PR empilées.
4. Tous les contrôles doivent passer et les conversations être résolues avant fusion.

Règles détaillées : `AGENTS.md`. Sécurité : `SECURITY.md`.
